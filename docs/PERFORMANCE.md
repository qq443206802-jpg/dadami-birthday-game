## 浏览器性能采样

使用本任务的内嵌Chromium浏览器，桌面1280×720和手机横屏844×390尺寸。正式访问不显示性能面板；测试URL使用?perf=1。帧率为游戏更新循环的实际采样，不能等同于所有设备的显示帧率。

| 场景 | 有效采样时长 | 平均帧率 | P95帧间隔 | 超过50ms的帧 |
|---|---:|---:|---:|---:|
| 本地524移动 / 箱子，优化后 | 39.4秒 | 59.4 | 17.8ms | 0 |
| 公网细胞观察问答 | 60.5秒 | 59.5 | 17.9ms | 0 |
| 公网细胞房移动 | 27.4秒 | 59.5 | 17.9ms | 0 |
| 公网526移动 / 布置 | 44.0秒 | 59.5 | 17.8ms | 0 |
| 公网宿舍移动 | 26.7秒 | 59.5 | 17.9ms | 0 |
| 公网电子蛋糕独立页面 | 34.9秒 | 25.0 | 40.1ms | 0 |

蛋糕主动限制绘制频率，上限30帧，实测约25帧，适合缓慢旋转。公网首次初始化记录到2次浏览器长任务，最大约302ms；组会问答/视口切换期间记录到一次约52ms的长任务。这些情况未造成持续停顿，但不能承诺所有设备完全无卡顿。

旧采样中“dorm-dialog”含蛋糕主动暂停校园循环的时间，不作为运行帧率；采样器已补充弹窗切换时清除间隔，避免把主动暂停当作卡顿。正式生日弹窗期间仍暂停校园循环。

## 已做的性能调整

- 两张角色素材由PNG转为保留透明背景的WebP，合计从约3.14 MB降至0.73 MB；原始PNG保留在本地。
- 避免每帧重复写入相同的时钟与互动提示，减少不必要的DOM布局和节点创建。
- 蛋糕绘制频率与像素比设有上限；页面隐藏时暂停；蛋糕弹出时暂停校园循环。
- Vite相对路径和动态素材base一致，避免项目子目录部署后图片/弹窗404。
