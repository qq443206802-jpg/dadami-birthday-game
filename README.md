# dadami birthday game

制作人：**Moon**。中文封面：今天，给达大米过生日。

Phaser 3 / TypeScript / Vite，原创绘本双鸟合作生日冒险。

## 启动
安装 Node.js 后，在此目录运行：

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的本地地址。或者双击 `启动游戏.cmd`。开发服务器运行时请保留终端窗口。

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

`dist` 是可部署到静态托管的网页文件，不能直接用文件协议双击index.html代替HTTP服务器。

## 蓝色生日电子蛋糕

打开 `/birthday-cake.html` 可单独预览；源码在 `public/birthday-cake.html`，该文件无外部依赖，可单独双击运行。支持自动旋转、三根跳动烛火、点击吹灭和重新点亮。

游戏封面“先试新关卡”→“终点 · 蓝色生日蛋糕”可直接试玩。正式路线到达五栋宿舍房门时自动弹出，点击“带着祝福睡个好觉”进入双鸟在蛋糕前安睡的室内结尾。说明和参考来源见 `docs/BIRTHDAY-CAKE.md`。

## 游玩
左右箭头/A、D移动，空格跳跃，蓝鸟在空中再次按空格可扑翼，E互动/开宝箱，Q切换。手机横屏使用屏幕按钮，可同时按住方向与跳跃。掉落会回到安全点，不丢物品。浏览器本地自动存档，不跨设备同步。

路线：西南门校园公路 → 图书馆书车/宝箱 → 药学院五楼 → 524实验室贺卡宝箱 → 细胞房图案/星星宝箱 → 研究生日常 → 526生日派对 → 西园五栋。

点击右上角齿轮修改称呼、双鸟名字与祝福。发布给寿星时，可先修改 `src/state.ts` 的 `defaultConfig`，再构建，使对方打开即看到你的文字。无需运行时AI或账号。

图书馆采用公开建筑参考；524和细胞房根据用户实景照片转绘；其余外观/室内有明确示意标注。来源见 `docs/ASSETS.md`。

## 当前版本内容

门口保安拼图、图书馆双鸟搭路与找不同、电梯消消乐、524师妹基础问答、细胞房师兄问答与显微镜匹配、双鸟研究生日常、35秒老师周报躲避、下班整理、526生日派对、西园五栋尾声均已接入主线。

小黄擅长推拉物件；小蓝能额外扑翼。图书馆中推书车后，小黄会先驻守，切换小蓝登高拉绳放桥，两鸟会合后才能开箱。可从下方跳上小平台；主要难度在观察路径和能力组合。

校园时间以约12分钟一个昼夜循环，从07:00出发；晴、多云、雨按90秒天气段轮换，并渐变雨量。室外有雨丝、涟漪、星光与夜灯，室内显示窗外天气。切到后台暂停，不使用真实天气API；重新载入从早晨开始，关卡/物品存档保留。

主角按用户两张真实鹦鹉照片更新：蓝鸟白额头、黑白波纹、天蓝胸腹；黄鸟柠檬黄头、浅黄绿色身体、淡色翅膀与蓝颊斑。
